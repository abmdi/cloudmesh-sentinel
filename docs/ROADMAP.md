# 365-Day Roadmap

## Phase 1 — Foundation (weeks 1–4)
1. Repository bootstrap, health API, tests and CI.
2. PostgreSQL schema, migrations and local Docker environment.
3. AWS read-only inventory: VPC, subnets, route tables and security groups.
4. Normalized resource model, inventory API, pagination and fixture-based tests.
5. Autonomous agent in sandbox: issue selection, patch generation, tests and PR-only publication.

## Phase 2 — Discovery (months 2–3)
AWS topology, cloud permission audits, inventory diffs and tracing.

## Phase 3 — Multi-cloud (months 4–6)
Azure VNet/NSG inventory, cross-cloud normalization and routing checks.

## Phase 4 — Observability (months 7–9)
OpenTelemetry, Prometheus, Kubernetes signals and anomaly detection.

## Phase 5 — Production maturity (months 10–12)
Dashboard, performance, hardening, docs, release automation and stable APIs.

## Success measures
Useful merged changes, passing tests, coverage, issues closed, releases and security posture; not raw commit count.
